# Tutorial template

Copy `tutorial.qmd.template` into the relevant subject folder, rename it with a `.qmd` extension, and replace the example material.

Set `date:` to the publication date or the most recent substantial revision. This one field controls the automatic Latest list; routine typo fixes do not need a new date.

The preferred structure is:

1. Overview
2. Why this matters
3. Mental model
4. Before you start
5. Procedure
6. Verify the result
7. Troubleshooting
8. Quick reference
9. References

Not every tutorial needs every section. Remove empty sections rather than publishing placeholders, but always keep a clear purpose, prerequisites where relevant, and a way to verify the outcome.
