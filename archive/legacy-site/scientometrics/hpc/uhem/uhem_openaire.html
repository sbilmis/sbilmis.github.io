Funding — partial, from structured grant links only
Direct funding information is not available from the OpenAIRE Graph. OpenAIRE does not index funding-acknowledgment text, so it cannot tell you which papers credit UHeM, nor return a complete funding profile for a paper. What it does expose is the sparse set of structured grant links that publishers or repositories happened to deposit — present for only 56 of 674 papers (8%). Read the figures here as an illustrative lower bound, not a funding census.

Can OpenAIRE find these on its own?
OpenAIRE's API has no acknowledgment-text field (see docs/database_discrepancies.md), so it cannot run the query Scopus/WoS run. What it can do is a free-text keyword search over title/description/subjects — run for real, restricted to countryCode=TR to cut obvious noise, using the same phrase list the Scopus/WoS extraction uses. Both the hits and the misses matter here, so both are shown as found, unedited.

Methodology
ⓘ How the comparison is built
The corpus is defined by Scopus (papers whose funding text credits UHeM — OpenAIRE cannot search acknowledgment text, so it cannot define this corpus independently, and the independent-search section above measures exactly how badly a keyword substitute does at that job). Each article DOI is looked up in the OpenAIRE Graph API; 674 of 676 (100%) are found — that match rate is the coverage comparison. For the matched papers we compare, per year: record counts (coverage), OA share (Scopus native flag vs OpenAIRE bestaccessright = OPEN), and total citations (Scopus vs OpenAIRE BIP!). "Green" means a repository copy exists — the main reason OpenAIRE's OA share exceeds Scopus's. Funder links are a lower bound: OpenAIRE only carries grants that publishers/repositories deposited (~8% of papers here). SJR quartiles, and institution/ researcher leaderboards, are not reproduced from OpenAIRE.
