# Legacy site archive

`legacy-site/` is the read-only snapshot of the HTML site that preceded the Quarto migration.

New site content belongs in Quarto `.qmd` files at the repository root. Do not add new pages to this archive. The Quarto post-render step republishes selected legacy applications at their original URLs so existing links continue to work. The old capitalized `Tutorials/` tree stays archive-only because it conflicts with the new lowercase `tutorials/` output on case-insensitive filesystems.
